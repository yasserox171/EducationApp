# تطبيق المركز التعليمي — الواجهة الأمامية (Flutter)

تطبيق موبايل (iOS + Android من كود واحد) لمركز تعليمي واحد: أستاذ واحد
يضيف كل المحتوى، والتلاميذ يتابعون الدروس — مجانًا وبدون نظام دفع.
يعمل بنمط **offline-first**: الدروس المحمَّلة تُقرأ بلا إنترنت، والتقدّم
يُخزَّن محليًا ويُرسل عند عودة الاتصال.

هذا المستودع يحتوي **الواجهة الأمامية فقط**؛ الخادم منفصل ويُعرَّف بـ
`BASE_URL` في ملف `.env`.

## تجربة سريعة بلا خادم

النسخة التجريبية تعمل ببيانات جاهزة (٣ مواد، ٩ دروس، ٣٢ فقرة) وحسابين:

| الدور | البريد | كلمة السر |
|---|---|---|
| أستاذ | `prof@demo.dz` | `demo1234` |
| تلميذ | `eleve@demo.dz` | `demo1234` |

```bash
cp .env.example .env      # ثم اضبط DEMO_MODE=true
flutter run
```

**آخر نسخة APK جاهزة للتثبيت:**
[education-app-demo-3.apk](https://github.com/yasserox171/EducationApp/releases/download/apk-3/education-app-demo-3.apk)
(~٥٦ م.ب، موقّعة بمفتاح تطوير — للتجربة لا للنشر).

لبناء نسخة جديدة: تبويب **Actions** → **بناء APK** → **Run workflow**.
التفاصيل في [`docs/DEMO.md`](docs/DEMO.md).

## البدء السريع

```bash
git clone <repo> && cd EducationApp
./tool/bootstrap.sh          # ينشئ .env ويولّد android/ و ios/ ويجلب الحزم
# ضع عنوان الخادم في .env:  BASE_URL=https://api.example.com/v1
flutter run
```

> `./tool/bootstrap.sh` يحتاج Flutter مثبَّتًا (>= 3.27) وPython 3.
> مجلدا `android/` و`ios/` يُولَّدان بـ `flutter create` — بعد أول تشغيل
> ناجح أضِفهما إلى المستودع (`git add android ios`) ليصبحا جزءًا من
> المشروع مع أي تعديلات لاحقة (التوقيع، الأيقونات…).

بدون `.env` (في سلاسل البناء مثلًا):

```bash
flutter run --dart-define=BASE_URL=https://api.example.com/v1
```

إن كان `BASE_URL` ناقصًا، يعرض التطبيق شاشة «الإعداد غير مكتمل» بدل
الانهيار.

### شاشات التلميذ

- **المواد** ← **دروس المادة**: عند أول دخول لمادة يُطلب اختيار الطور
  (متوسط/ثانوي)، ثم تُعرض دروس ذلك الطور فقط مع مؤشّر الحالة
  (لم يبدأ / قيد التقدم / مكتمل) وزر التحميل.
- **عارض الدرس**: الفقرات بالترتيب مع تنقّل تالي/سابق، حفظ آخر موضع
  تلقائيًا، وتشغيل الفيديو من الملف المحمَّل إن وُجد. النصوص تُرسم فيها
  معادلات LaTeX، وتحت كل فيديو قائمة مرفقات PDF بزر تنزيل.
- **الكويز**: التلميذ يجيب على كل الأسئلة دون أن يرى صحيح/خطأ، ثم تظهر
  «نتيجة الكويز»: العدد الصحيح من المجموع ومراجعة لكل سؤال. الخروج في
  المنتصف يحفظ الإجابات محليًا ويستأنف من أول سؤال غير مُجاب.
- **تقدّمي**: نسبة الإكمال لكل مادة، محسوبة محليًا (تعمل بلا إنترنت).
- **الإعدادات**: تغيير الطور لكل مادة، المساحة المستعملة وحذف التحميلات،
  حالة المزامنة وإعادة محاولة ما فشل، تسجيل الخروج.

### شاشات الأستاذ

- **لوحة المواد**: إضافة/تعديل/حذف مادة.
- **دروس المادة**: إضافة/تعديل/حذف درس، نشر أو إخفاء، وإعادة ترتيب بالسحب.
- **محرّر الدرس**: إضافة فقرات (نص/فيديو/كويز)، تعديلها، حذفها، وإعادة
  ترتيبها. رفع الفيديو بشريط تقدم وإمكانية الإلغاء، مع رفض الملفات التي
  تتجاوز الحد قبل بدء الرفع.
  - **الفقرة النصية**: شريط أدوات رياضيات وزر «إدراج معادلة» لكتابة
    LaTeX بين فاصلَي `$$`، مع معاينة حية تتحدّث مع كل حرف.
  - **فقرة الفيديو**: زر «إضافة PDF» لإرفاق ملفات بشريط تقدم وحذفها.
  - **فقرة الكويز**: عدة أسئلة في الفقرة الواحدة، لكل سؤال خياراته
    وإجابته الصحيحة وشرحه.
- **الإحصائيات**: عدد التلاميذ، نسبة إكمال كل درس، متوسط نتائج الكويزات.

## حالة التحقّق

على **Flutter 3.47.2 / Dart 3.13.2**:

- `flutter analyze` → **بلا أي ملاحظة**.
- `flutter test` → **٣٨ اختبارًا كلها ناجحة**:
  - النماذج وتحويلها من/إلى JSON وصفوف قاعدة البيانات،
  - طابور الإرسال: التراجع الأسّي، الدمج، إعادة المحاولة،
  - قاعدة البيانات على SQLite حقيقي: الفلترة بالطور، الحذف المتسلسل،
    دمج التقدّم دون دهس التغييرات المحلية، مسح البيانات عند الخروج،
  - إقلاع التطبيق: التحويل حسب الإعداد/الدخول، اتجاه RTL، تحقّق النموذج.
- `pubspec.lock` مرفوع عمدًا: هو نفس مجموعة الحزم التي جرى التحقّق منها.

**لم يُتحقَّق منه هنا:** بناء APK/IPA فعلي وتشغيل على جهاز — البيئة التي
بُني فيها المشروع لا تحتوي Android SDK ولا Xcode. شغّل `./tool/bootstrap.sh`
ثم `flutter run` على جهازك لأول تشغيل حقيقي.

## ملاحظات أمنية

- `.env` **غير مرفوع** إلى المستودع (`.gitignore`). ارفع `.env.example` فقط.
- رمز الدخول (JWT) يُخزَّن في `flutter_secure_storage`
  (Keychain / EncryptedSharedPreferences) — لا في SharedPreferences.
- عند تسجيل الخروج تُمسح البيانات المحلية والملفات المحمَّلة: الجهاز قد
  يستعمله تلميذ آخر.
