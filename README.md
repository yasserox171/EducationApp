# تطبيق المركز التعليمي — الواجهة الأمامية (Flutter)

تطبيق موبايل (iOS + Android من كود واحد) لمركز تعليمي واحد: أستاذ واحد
يضيف كل المحتوى، والتلاميذ يتابعون الدروس — مجانًا وبدون نظام دفع.
يعمل بنمط **offline-first**: الدروس المحمَّلة تُقرأ بلا إنترنت، والتقدّم
يُخزَّن محليًا ويُرسل عند عودة الاتصال.

هذا المستودع يحتوي **الواجهة الأمامية فقط**؛ الخادم منفصل ويُعرَّف بـ
`BASE_URL` في ملف `.env`.

---

## البدء السريع

```bash
git clone <repo> && cd EducationApp
./tool/bootstrap.sh          # ينشئ .env ويولّد android/ و ios/ ويجلب الحزم
# ضع عنوان الخادم في .env:  BASE_URL=https://api.example.com/v1
flutter run
```

> `./tool/bootstrap.sh` يحتاج Flutter مثبَّتًا (>= 3.27) وPython 3.
> مجلدا `android/` و`ios/` يُولَّدان بـ `flutter create` — بعد أول تشغيل
> ناجح أضِفهما إلى المستودع (`git add android ios`) ليصبحا جزءًا من
> المشروع مع أي تعديلات لاحقة (التوقيع، الأيقونات…).

بدون `.env` (في سلاسل البناء مثلًا):

```bash
flutter run --dart-define=BASE_URL=https://api.example.com/v1
```

إن كان `BASE_URL` ناقصًا، يعرض التطبيق شاشة «الإعداد غير مكتمل» بدل
الانهيار.

## ما هو جاهز الآن

| الطبقة | الحالة |
|---|---|
| هيكلة المشروع والطبقات | ✅ |
| الإعدادات (`.env`، بلا أي رابط ثابت في الكود) | ✅ |
| قاعدة البيانات المحلية (sqflite) + DAOs | ✅ |
| طبقة الشبكة (Dio + اعتراض JWT + أخطاء عربية) | ✅ |
| المصادقة + التخزين الآمن للرمز | ✅ |
| المستودعات offline-first (محتوى، تقدّم، أستاذ) | ✅ |
| طابور الإرسال (outbox) ومحرّك المزامنة | ✅ |
| مدير تحميل الدروس (مع الاستئناف وحذف الملفات) | ✅ |
| الموجّه (GoRouter) + حراسة الأدوار | ✅ |
| السمة + العربية/RTL الكامل | ✅ |
| شاشة تسجيل الدخول | ✅ |
| **فضاء التلميذ:** المواد، الدروس، اختيار الطور، عارض الدرس، الكويز، التحميل، تقدّمي، الإعدادات | ✅ |
| **فضاء الأستاذ:** المواد، الدروس وإعادة الترتيب، محرّر الفقرات، رفع الفيديو، الإحصائيات | ✅ |

### شاشات التلميذ

- **المواد** ← **دروس المادة**: عند أول دخول لمادة يُطلب اختيار الطور
  (متوسط/ثانوي)، ثم تُعرض دروس ذلك الطور فقط مع مؤشّر الحالة
  (لم يبدأ / قيد التقدم / مكتمل) وزر التحميل.
- **عارض الدرس**: الفقرات بالترتيب مع تنقّل تالي/سابق، حفظ آخر موضع
  تلقائيًا، تصحيح فوري للكويز، وتشغيل الفيديو من الملف المحمَّل إن وُجد.
- **تقدّمي**: نسبة الإكمال لكل مادة، محسوبة محليًا (تعمل بلا إنترنت).
- **الإعدادات**: تغيير الطور لكل مادة، المساحة المستعملة وحذف التحميلات،
  حالة المزامنة وإعادة محاولة ما فشل، تسجيل الخروج.

### شاشات الأستاذ

- **لوحة المواد**: إضافة/تعديل/حذف مادة.
- **دروس المادة**: إضافة/تعديل/حذف درس، نشر أو إخفاء، وإعادة ترتيب بالسحب.
- **محرّر الدرس**: إضافة فقرات (نص/فيديو/كويز)، تعديلها، حذفها، وإعادة
  ترتيبها. رفع الفيديو بشريط تقدم وإمكانية الإلغاء، مع رفض الملفات التي
  تتجاوز الحد قبل بدء الرفع.
- **الإحصائيات**: عدد التلاميذ، نسبة إكمال كل درس، متوسط نتائج الكويزات.

## البنية باختصار

```
lib/
├── main.dart          الإقلاع: env → قاعدة البيانات → الجلسة → runApp
├── app/               MaterialApp + كل مزوّدات Riverpod
├── core/              الإعدادات، الأخطاء، الشبكة، التخزين، الموجّه، السمة، النصوص
├── data/              النماذج، خدمات API، المستودعات، المزامنة
└── features/          auth / student / teacher / shared
```

- **إدارة الحالة:** Riverpod 2 (بدون توليد كود). الأسباب في
  [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
- **قاعدة صارمة:** الشاشات لا تلمس Dio ولا sqflite — المستودعات فقط.

## ملاحظات أمنية

- `.env` **غير مرفوع** إلى المستودع (`.gitignore`). ارفع `.env.example` فقط.
- رمز الدخول (JWT) يُخزَّن في `flutter_secure_storage`
  (Keychain / EncryptedSharedPreferences) — لا في SharedPreferences.
- عند تسجيل الخروج تُمسح البيانات المحلية والملفات المحمَّلة: الجهاز قد
  يستعمله تلميذ آخر.
